## About The Project

English - German vocabulary from the book "MORE! 1", sorted by unit (units 1–15 of the current workbook), with an example sentence and its German translation for most entries.

Help your child or yourself to learn the vocabulary from this book quickly!

**Website: <https://reinsch82.github.io/vocabulary/>**

* **Printable worksheets (PDF):** the German example sentences of a unit with space to write the English translation, plus a solutions sheet in the same layout.
* **Online vocabulary trainer:** flashcards or typing, Deutsch → English, English → Deutsch or whole sentences, with spaced repetition and pronunciation. Progress is stored in the browser (localStorage), no account needed.
* **Word list:** all units as tables, searchable, with the option to hide one language and tap a row to reveal it.
* **Files for flashcard apps** (see below).

This is a fork of [lemon3/vocabulary](https://github.com/lemon3/vocabulary) by Wolfgang Jungmayer.

## Usage

### iOS (Apple)

#### iOS "amazing flash cards" app
1) download [amazing-flash-cards](https://apps.apple.com/at/app/amazing-flash-cards/id1511674871) from the App Store (apple).
2) download e.g. [unit 1 vocabulary](https://reinsch82.github.io/vocabulary/csv-file-example/more1-unit01.csv).
3) import this file into the app
   1) locate the csv file (usually under downloads in the files app)
   2) use the "share menu" (longpress) and "share" the file in "Flash Cards".
   ("Copy to Flash Cards" should appear as an option, it might be hidden under "More").

#### iOS "wordim" app
1) download [Wordim - Personal vocabulary](https://apps.apple.com/us/app/wordim-personal-vocabulary/id1662281843) from the App Store (apple).
2) download e.g. [unit 1 vocabulary](https://reinsch82.github.io/vocabulary/wordim/more1-unit01.wordim).
3) import this file into the app
   1) "plus button" (bottom left) > import > locate the file > hit import

#### iOS "plain flashcards" app
1) download [plain flashcards](https://apps.apple.com/at/app/plain-flashcards/id971833934) from the App Store (apple).
2) download e.g. [unit 1 vocabulary](https://reinsch82.github.io/vocabulary/plain-flashcards/more1-unit01.zip).
3) import this zip file into the app

#### iOS "smart repetition" app
1) download [smart repetition](https://apps.apple.com/us/app/smart-repetition/id1556865655) from the App Store (apple).
2) download e.g. [unit 1 vocabulary](https://reinsch82.github.io/vocabulary/text-file/more1-unit01.txt).
3) import this file into the app
   1) menu > loading collections > load from file

#### iOS "simple anki" app
1) download [simple anki](https://apps.apple.com/us/app/simple-anki/id1625870857) from the App Store (apple).
2) download e.g. [unit 1 vocabulary](https://reinsch82.github.io/vocabulary/csv-file/more1-unit01.csv).
3) import this file into the app

### Android os (Google)
#### "smart repetition / memorycard" app
1) download [smart repetition / memorycard](https://play.google.com/store/apps/details?id=com.kuraeva.memorycard) from the Google Play store.
2) download e.g. [unit 1 vocabulary](https://reinsch82.github.io/vocabulary/text-file/more1-unit01.txt).
3) import this file into the app

## Development

The vocabulary lives in `src/more1-unitXX.json`, one file per unit; everything else is generated from it:

```json
{
  "name": "More! 1 - UNIT 1",
  "words": [
    { "de": "geben", "en": "to give", "example": "Give me your school bag.", "example_de": "Gib mir deine Schultasche." }
  ]
}
```

Entries without an example sentence (mostly phrases) have empty `example` and `example_de`.

```sh
npm ci
npm run build   # writes everything to dist/
```

* `config/webpack.prod.js` – list of units and output formats
* `config/toCSV.js`, `toTXT.js`, `wordim.js`, `plainFlashCards.js` – flashcard app formats
* `config/toPDF.js` – worksheets and solutions (pdfkit)
* `config/indexPage.js`, `trainerPage.js`, `vocabPage.js`, `pageStyle.js` – the web pages

On every push to `main`, the GitHub Actions workflow `.github/workflows/pages.yml` builds the project and deploys `dist/` to GitHub Pages. PDFs and HTML pages are not committed. The files in `dist/` in the repository are the old, original exports (units 1–10); the current files are the ones on the website.
